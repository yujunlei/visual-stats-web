## Positive References

Use these as product feel references, not as literal copies:

- Stata: command/results seriousness, professional statistics identity.
- SPSS: variable/data view separation, clear desktop application density.
- RStudio: pane-based research workbench, project/data/model context.
- EViews: econometrics and time-series desktop software feel.
- Academic journal regression tables: restrained typography, thin rules, publication-first reading.

## Anti-References

Avoid these directions:

- SaaS admin dashboard with colorful KPI cards.
- Logistics/control-center backend UI.
- Marketing homepage or landing page hero.
- Dark neon trading terminal unless explicitly exploring a separate variant.
- Purple-blue gradient productivity app.
- Glassmorphism, blurred cards, bokeh, decorative orbs.
- Big-screen data visualization wall.

## Existing Product Constraints To Preserve

- Three-column workbench.
- Left panel is a lightweight index.
- Center panel is the task focus.
- Right panel explains context and next actions.
- Data, Model, Result, Report are work modes, not a forced wizard.
- Results are readable before technical.
- Export includes publication-style tables.

## Visual Vocabulary

Good:

- thin borders;
- quiet panel headers;
- clear data tables;
- compact form controls;
- restrained badges;
- monospace formulas;
- explicit empty/error/running states;
- academic paper table preview.

Bad:

- too many cards;
- hero typography inside the app;
- colorful metric widgets;
- decorative SVG/gradient backgrounds;
- excessive rounded pills;
- generic dashboard charts;
- vague AI assistant copy.
