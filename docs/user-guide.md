# Visual Stats Lab 使用说明

Visual Stats Lab 是面向统计、经管、管理和社会科学研究的桌面式统计建模工作台。它的核心流程是：选择模型、导入数据、设置字段和变量、运行模型、阅读结果、保存历史数据，并导出论文三线表或自定义论文表。

本文面向实际使用者。内部打包和授权发行工具见文末附录。

## 1. 启动与授权

打开应用后，顶部会显示当前授权状态。

- 开发模式：本地开发环境默认开放全部本地功能。
- 试用模式：可在授权弹窗中启动试用，试用期内可使用授权允许的功能。
- 已激活：输入有效授权密钥后，应用会显示授权方案、到期时间和可用模型包。
- 授权过期或离线宽限期结束：应用会限制运行模型、论文表导出或高级模型包。

如需激活或刷新授权：

1. 点击顶部授权状态入口。
2. 输入授权密钥并激活，或点击刷新授权。
3. 如应用提示需要联网，请联网后重新刷新。

授权通常控制：

- 可运行的模型包：核心、进阶、实验。
- 是否允许导出论文表。
- 授权期限和离线宽限期。

## 2. 快速上手

推荐按下面的顺序完成一次完整分析：

1. 在建模工作台中打开模型库。
2. 点选一个模型，并点击“使用此模型”确认。
3. 上传 CSV 或 XLSX 数据。
4. 在字段角色面板中确认 ID、Time 和 Group 字段。
5. 打开“设置变量与参数”。
6. 依次选择因变量、核心解释变量、控制变量和模型参数。
7. 点击“保存并运行”或回到主界面点击“运行模型”。
8. 在结果页阅读核心结论、模型摘要、系数估计和附加结果。
9. 使用“保存数据”保存当前数据、配置和结果。
10. 进入“自定义导出表”导出论文表。

## 3. 建模工作台

建模工作台是日常分析的主入口。顶部用于切换“建模工作台”和“自定义导出表”，右上角提供上传、数据表和运行等常用操作。

### 选择模型

首次进入时没有默认模型，需要先打开模型库并确认一个模型。

模型库按研究任务分组：

- 数据探索
- 差异检验
- 相关关系
- 回归建模
- 面板与固定效应
- 机制检验
- 空间与扩展模型

点击模型卡片只会进入“待应用”状态。必须点击底部“使用此模型”，主界面才会切换到该模型。

模型卡片上的成熟度含义：

- 稳定：已作为常规功能维护，并有自动测试或 fixture 覆盖。
- 预览：适合探索和方案设计，正式论文建议用权威软件复核。
- 实验：默认可见，但仍保留实验标记，不建议直接作为最终论文结论。

### 导入数据

支持导入：

- CSV
- XLSX

CSV 和 XLSX 都会走导入解析流程。导入后，系统会打开字段角色确认面板。

导入限制：

- 文件大小有限制，超过限制会直接提示。
- 行数和字段数有限制，超过限制会停止解析并提示。
- 若发现缺失值，会弹出缺失值提醒，用户可以取消导入或继续设置字段。

如 XLSX 读取较慢，通常是文件较大、工作表内容复杂或列数较多。建议先保留用于分析的工作表和字段，再重新导入。

### 设置 ID / Time / Group 字段

字段角色面板用于确认数据维度：

- ID 字段：实体唯一标识，例如公司、用户、城市。可多选。
- Time 字段：时间维度，例如 year、month、date。只能选择一个。
- Group 字段：分组维度，例如行业、地区、实验组。可多选。

维度字段不会进入普通因变量和自变量候选列表，主要用于面板、固定效应、分组和后续结果解释。

### 设置变量与参数

点击“设置变量与参数”会打开变量设置弹窗。建议按三步完成：

1. 选择因变量 Y。
2. 选择核心解释变量 X。
3. 选择控制变量。

核心解释变量和控制变量互斥：一个变量选为核心解释变量后，不会再作为控制变量候选；反之亦然。

不同模型会展示不同参数。例如：

- 线性回归：标准误、控制变量等。
- 面板固定效应：Panel ID、解释变量、标准误等。
- 高维固定效应：吸收固定效应 absorb、解释变量、聚类字段等。
- 空间模型：空间键、解释变量、空间权重文件 W 等。

保存变量设定后，系统会根据当前配置判断是否可以运行。若缺少必填变量，运行按钮会禁用并提示原因。

## 4. 模型运行与失败处理

点击运行后，系统会显示运行状态。运行成功后进入结果页。

如果运行失败，会弹出运行失败弹窗，并显示失败原因、当前模型和公式。常见原因包括：

- 未选择必需变量。
- 自变量高度相关，导致模型矩阵不可逆。
- 固定效应吸收后变量共线。
- 空间权重文件与空间键不匹配。
- 可用观测太少。

处理方式：

1. 返回变量设定。
2. 减少高度相关变量。
3. 检查固定效应、聚类字段或空间权重文件。
4. 重新运行。

失败状态不会改变原始数据，也不会自动覆盖已有历史数据。

## 5. 结果阅读

结果页用于阅读统计结果，而不是堆叠所有日志。一般包括：

- 核心结论：自然语言解释结果。
- 模型摘要与系数估计：公式、样本量、R²、F 检验、系数表等。
- 稳健性 / 附加结果：模型输出的次级表格、设定表、固定效应或空间诊断表。
- 导出入口：导出当前结果或论文表。

核心结论会基于当前结果自动生成。例如，它会解释模型解释力、整体显著性、显著变量数量等。自然语言结论是阅读辅助，正式论文写作仍建议结合研究假设和领域知识判断。

## 6. 历史数据

左侧“项目索引”中可以保存和管理历史数据。

点击“保存数据”会保存当前数据、模型配置和结果。保存后会出现在“历史数据”区域。

历史数据支持：

- 恢复：点击历史数据条目，可恢复当时的数据、模型、变量配置和结果。
- 置顶：将重要记录固定在列表前面。
- 收藏：标记常用或重要记录。
- 重命名：在管理模式中修改名称。
- 删除：删除本地历史记录。
- 标签和备注：在管理模式中为历史数据增加说明。

筛选入口包括：

- 最近
- 置顶
- 收藏
- 全部

如果历史数据采用“仅结果”保存模式，则可以恢复结果阅读和导出，但不能重新运行模型，因为原始 rows 没有保存。

## 7. 自定义导出表

点击顶部“自定义导出表”进入 Report 工作区。该工作区独立于建模流程，主要用于把当前结果和历史结果整理成论文表。

默认状态下，自定义导出表会复用“当前结果论文三线表”。此时预览和直接导出的论文三线表应保持一致。

如需多模型、多列或自定义格式，点击“开始自定义多列表”。

### 可编辑内容

在自定义模式下可以编辑：

- 表名和注释。
- 模型比较来源。
- 来源列和多级表头。
- 变量行显示、隐藏、重命名和排序。
- 统计行显示、隐藏、重命名和排序。
- 小数位、括号统计、星号阈值、缺失值显示、Yes/No 显示。
- 用户模板。

右侧论文表预览会实时反映左侧编辑项。预览用于查看应用内效果，正式导出的 Excel、Word 和 HTML 会使用统一的论文三线表样式。

### 来源列

来源列可以来自：

- 当前结果。
- 已保存的历史数据结果。
- 模型比较表。

模型行默认使用模型简称。例如：

- 线性回归显示 OLS。
- 高维固定效应显示 REGHDFE。
- 空间模型显示 SAR、SDM、SEM 等简称。

用户可以手动覆盖列名、一级分组和模型行。

### 用户模板

如果经常使用同一种论文表格式，可以保存为用户模板。模板可用于：

- 复用表名、注释和显示规则。
- 复用变量行和统计行配置。
- 设为默认模板。
- 复制或删除。

内置预设已取消。当前阶段建议使用用户模板作为论文表复用机制。

## 8. 模型与模型包说明

Visual Stats Lab 的模型按模型包管理：

- 核心模型包：数据探索、差异检验、相关关系、基础回归。
- 进阶模型包：面板固定效应、高维固定效应、机制检验。
- 实验模型包：空间计量、门槛回归、复杂机制模型。

授权会决定可用模型包和单模型权限。若某些模型不可见或不可运行，请检查授权状态和产品 profile。

### 固定效应模型

面板固定效应和高维固定效应属于进阶能力。

当前支持：

- 面板固定效应组内估计。
- 多维固定效应吸收。
- 普通、稳健和单向聚类标准误。
- 固定效应摘要、吸收自由度和共线变量提示。

注意：完整 Stata / reghdfe 所有后估计命令、多向聚类、权重和所有自由度修正并不都在当前范围内。已覆盖 fixture 范围会按逐项一致目标维护。

### 空间模型

空间与扩展模型中包括：

- SLX
- SAR
- SEM
- SDM
- SDEM
- SAC
- GNS
- 空间面板 SDM
- 空间 Logit

SLX、SAR、SEM、SDM 已按 PySAL / spreg fixture 范围验证并标记为稳定。其他复杂空间模型仍为预览。

空间模型通常需要：

- 因变量 Y。
- 空间键 / 区域 ID。
- 核心解释变量。
- 可选的独立空间权重文件 W。

W 文件支持：

- edge-list：包含 from / to / weight。
- 方阵 CSV：第一行和第一列为空间 ID。
- GAL / GWT。

如果 W 与空间键无法匹配、有效边为 0、样本过少或矩阵不可逆，模型会失败并给出提示。

## 9. 常见问题

### 为什么不能直接上传数据？

当前流程要求先选择模型，再导入数据。这样系统可以根据模型要求引导后续字段和变量设置。

### 为什么变量没有默认值？

为了避免误把第一列或某个数值列当作因变量/自变量，当前不会默认选择变量。用户必须主动完成变量设定。

### 为什么核心解释变量和控制变量不能重复？

两者语义不同。核心解释变量用于回答主要研究问题，控制变量用于降低遗漏变量偏误。重复选择会造成公式和解释混乱，因此系统强制互斥。

### 为什么默认自定义导出表和直接论文三线表要一致？

默认自定义导出表表示“当前结果论文三线表”。只有当用户主动添加历史来源、修改行列或调整格式时，才进入真正的自定义多列表模式。

### XLSX 一直读取怎么办？

请先确认：

- 文件是否过大。
- 是否包含大量空列、隐藏列或复杂格式。
- 第一张工作表是否是标准二维表。
- 是否可以另存为 CSV 后导入。

如果仍然读取异常，建议删除无关工作表和格式，只保留分析字段后重新上传。

### 授权有效但模型不可见怎么办？

可能原因：

- 授权只包含部分模型包。
- 产品 profile 没有打包该模型。
- 授权中限制了单模型范围。

请刷新授权，或联系发行人员确认授权方案。

## 10. 内部发行人员附录：Packager Studio

Packager Studio 是内部发行工具，不会随正式客户端分发。它用于：

- 生成产品 profile。
- 选择启用哪些模型包和单模型。
- 注入授权服务器地址和授权公钥。
- 生成 license key 记录。
- 执行 Windows NSIS 打包流水线。

常用命令：

```bash
npm run desktop:dev
npm run packager:studio
npm run desktop:dist
npm run license:keypair
npm run license:server
```

安全规则：

- 私钥只保存在授权服务器或内部签发环境。
- 私钥不得进入 Git。
- 私钥不得进入正式客户端或安装包。
- `license-keys.json` / `license-keys.csv` 属于发行记录，应妥善保存，不应提交到仓库。

打包台第一版是产品能力级控制：未选择的模型不会在 UI 中展示，也不可选择或运行；它不承诺从最终 JavaScript bundle 中物理删除所有未选模型代码。
